# HIV-Surveillance: A Simulation and Analysis
This project is an example of HIV surveillance. I simulate HIV data similar to what might be found in eHARS (NO PERSONAL DATA IS USED), perform QA, and analyze my simulated data. 

---

## 🧠 Objective
The goal of this project is to show an example of analyzing HIV data. The type of data being used is typically not public because of the sensative nature and the legal issues with using such data. To circumvent this, I simulate my own data in an attempt to replicate the type of data typically used.
